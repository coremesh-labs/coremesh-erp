# Agent-Leitfaden

Dateien für KI-Agenten, die Sachbearbeiter in einer CoreMesh-Installation unterstützen.
Das Setup-Werkzeug legt sie in das Installationsverzeichnis (neben `console`):

- `AGENTS.md` – Grundregeln, Konsole, Module, typische Abläufe (wird bei Updates ersetzt)
- `CLAUDE.md` – bindet `AGENTS.md` und `AGENTS.local.md` für Claude Code ein
- `AGENTS.local.example.md` – Vorlage für `AGENTS.local.md` mit den Angaben der
  Installation (wird nie überschrieben)
